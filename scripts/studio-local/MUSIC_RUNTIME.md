# 本地歌曲运行与恢复

`start_production.ps1` 启动媒体服务时分别指定 `--comfy http://127.0.0.1:8288` 和 `--music-comfy http://127.0.0.1:8188`。视觉工具使用独立引擎，ACE-Step 歌曲使用用户已经启动的原 ComfyUI。两个地址都必须为本机回环地址。未指定 `--music-comfy` 时继续使用 `--comfy`，兼容旧启动方式。

歌曲以填写的时长同时设置 ACE 文本条件和音频 latent；不会先生成 30 秒再选取最响片段。器乐和音效保留现有的长源音频裁切方式。当前本地服务上限仍为 30 秒。

每个歌曲任务在私有工作目录保存 `music-receipt.json`：原引擎、请求摘要、实际生成时长、原工作流、prompt ID 和产物信息。服务中断后从同一引擎查询并收集原任务；丢失提交响应时根据 `extra_data.studio_request_id` 查找队列和历史。没有找到或找到多个任务时保留不确定状态，不重新提交模型。收据已保存产物信息时可以直接收集，避免依赖有限的历史列表。旧任务沿用已记录的引擎和生成时长。

HTTP 端口在启动任务线程和恢复数据库之前绑定。Windows 使用独占端口；队列任务通过数据库条件更新领取。避免重复启动改写运行状态或重复领取任务。

2026-10-08 的真实验收中，12 秒四句英语歌曲通过 Whisper Small 与独立 Turbo 两次识别，服务在原生提交后中断，再启动后沿用同一 prompt，记录中只有一次原生推理。歌曲已通过实际浏览器审片、成片、字幕和交付包测试。该样片通过不保证所有歌词输入都能准确演唱；新版本仍需试听审片，错误版本应返工。

回归检查覆盖实际 HTTP 提交响应丢失、原引擎固定、历史消失后收集、无法确认时不重发、请求改变拒绝恢复，以及占用端口启动失败前不修改数据库。运行 `test_music_workflow.py`，并检查共享恢复路径的 `test_image_receipts.py`。
