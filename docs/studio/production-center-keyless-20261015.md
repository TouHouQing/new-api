# 制作中心优化与无 Key 生成验收

本地生产入口：[https://localhost:13443/studio](https://localhost:13443/studio)。本轮针对工作流 403、制作中心操作冗杂，以及实际操作中发现的恢复、队列、剪辑和审片问题完成了开发与验收。

## 生成方式

制作中心工作流不再创建、启用或依赖用户 API Key。登录账户提交项目任务后，服务端校验项目编辑权限、工作线程租约、账户状态、可选分组、模型权限和费用上限，再使用已配置的模型渠道执行。

费用预占和异步结算使用独立的任务账本，不保存调用密钥。额度、限流和正常计费继续生效。已有任务的旧令牌只用于读取历史消耗；禁用旧令牌不会阻止恢复任务。未明确结果的请求保留原任务记录供核对，避免自动重复生成。

真实验收账户原有 **1 个 Key，状态为禁用**。Qwen3.5-9B 文本、FLUX.2 Klein 4B 图片、Wan 2.2-TI2V-5B 首帧视频均真实生成成功；最终 Key 数量仍为 **1**。图片和文本各保留一个已完成版本，视频重试复用了这些结果。

## 用户体验发现与改动

| 发现的问题 | 当前行为 |
| --- | --- |
| 进入后面对九个并列页签，不知道从哪里开始 | 默认四步：故事与镜头 → 生成素材 → 剪辑与声音 → 检查与导出；其他五个工具按需展开 |
| 空项目也先进入工作流 | 空项目进入故事规划；已有镜头进入生成；已有可剪素材进入剪辑 |
| 费用解释、特效和定时设置挤在生成表单里 | 费用与服务说明、特效、定时和逐节点选择分别收起，保留简短费用摘要及执行范围 |
| 不知道哪些素材会重新生成 | 显示缺少素材与已有版本；支持先试第一个镜头、选择缺少素材 |
| 上传的视频也可能被第一镜头快捷选择选中 | 上传素材参与免费编辑，生成选择会跳过上传节点 |
| 重复点击可能创建重叠的生成任务 | 对仍在排队、生成、暂停或核对中的相同节点显示提示并阻止新提交 |
| 失败显示笼统技术错误 | 主提示使用简短中文，诊断详情可展开；参数错误可以进入对应节点修改 |
| 点击继续仍追踪已经失败的任务 | 明确失败的任务新建请求；已完成输入、预算和范围保留。成功、运行中或不明确的任务继续核对原记录 |
| 恢复任务错误地沿用新表单的确认 | 独立确认已保存任务的范围与原费用上限 |
| 暂停或取消后，旧任务仍占着生成队列 | 释放工作线程，保留上游任务记录；后续制作任务可以继续 |
| 零价格或固定价格任务完成后仍显示结算未完成 | 同步、异步成功、失败和中断恢复均更新账本的最终状态 |
| 自动分配时长依赖隐藏的 JSON 草稿 | 从当前镜头表单分配时长，可继续编辑并应用计划 |
| 剪辑页“制作配音或音乐”恢复了上次的深度工具 | 直接进入配音入口，保留其他工具作为可选切换 |
| 素材的编辑按钮只选中被弹窗遮住的画布节点 | 打开节点检查面板并关闭制作中心，可以预览、比较和修改 |
| 已自动进入时间线的视频再次加入后出现重复片段 | 已有当前版本的片段直接定位并进入编辑；新片段才添加 |
| 导出页“审核当前素材”没有进入审核界面 | 打开对应素材及版本的审片控件 |
| 审片返工计划创建后缺少下一步入口 | 重新生成进入生成页，剪辑返工进入时间线，声音返工进入素材制作 |
| 未完成字幕或未审核素材也可能继续交付 | 导出按钮给出具体阻断原因和修改入口；草稿预览仍可用于检查 |
| 本机桌面代理退出后，本地模型请求失败 | 本地 HTTP 与参考图上传绕过桌面代理；提交后的连接丢失按不明确结果处理 |
| 本机私有 ComfyUI 在加载 Wan 模型时原生崩溃 | 使用其动态显存加载方式；保留可选的兼容参数。真实首帧视频随后成功完成 |
| 对象存储按磁盘百分比预留空间，开发机器有空闲却暂停写入 | 本地对象存储使用明确的 2 GiB 预留值；低空间时仍阻止新写入，并清理本轮编译产物 |

## 真实交付验证

- 首帧视频：Wan 2.2，640×384，H.264，25 帧，实际时长 1.041667 秒。ComfyUI 执行耗时 85.65 秒，生成任务达到 100%，结算最终完成。
- 上述真实模型视频继续加入字幕并导出 MP4 与 ZIP，成片时长 1.054362 秒，H.264/AAC，640×384；实际解码与素材包完整性检查通过。
- 剪辑验收：两段已有素材拆成三个时间线片段，加入配乐、免费提示音、字幕、淡入淡出、水印，导出六秒的 640×360 MP4 和 ZIP。
- 使用独立、未登录的浏览器上下文打开审片链接，视频元数据与六秒时长正常；撤销后显示链接不可用。
- 字幕 SRT 导入、排序、导出实际完成；不完整行会阻止交付。重复片段字幕在交付前清除。
- 对下载文件进行 FFprobe 元数据检查和 FFmpeg 解码，检查 ZIP 完整性、字幕及交付清单。

证据位于 `output/playwright/production-center-20261014/`。其中 `model/status.json`、`model/completed-project.json` 记录真实模型结果和 Key 数量；`share-export-summary.json`、`collaborator-permissions.json`、`version-restore-summary.json` 记录操作结果。

## 更容易做出好视频的建议

1. 先确定用途、画幅和目标时长，再安排镜头。每个镜头明确主体、地点、一个主要动作、景别、运镜和光线。
2. 先准备角色与场景参考，并固定版本。先做一个短镜头，检查脸、服装、主体是否被裁切、运动是否自然，再制作其他镜头。
3. 本地 Wan 模型使用一个首帧，片段支持 1–10 秒；超出能力的长镜头先拆分。参考图构图要与目标画幅协调。
4. 粗剪后先调整镜头节奏，再加入配音、音乐和字幕。检查字幕重叠、声音音量以及实际导出布局。
5. 审片意见绑定具体时间点和素材版本，按意见只处理受影响部分，审核后交付。

本轮短视频用于验证生成和交付流程，画面美感、人物稳定性、长片连续性及不同模型组合仍需要逐片审看。质量检查可以发现技术问题，最终的人物、构图和叙事判断需要人工确认。

私有运行环境的内存定位参考了 [ComfyUI 官方模型构造代码](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy/ops.py)；采用动态加载后，以上首帧视频完成了实际验收。

本轮编译缓存、两个测试可执行文件及五个不再使用的本轮 Docker 镜像已经清理。模型、项目数据、生成素材和验收证据保留。
