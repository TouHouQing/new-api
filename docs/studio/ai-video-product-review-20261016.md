# AI 视频创作平台：产品复体验与改进方案

日期：2026-10-16，Asia/Shanghai。对象：本地生产版 `https://localhost:13443/studio`。对照：LibTV、小云雀、TapNow、即梦。

当前五步工作区已经有可用的制作基础。我建议继续沿用「想法 → 镜头 → 画面 → 剪辑与声音 → 导出」，把改造重点放在：用户能否知道下一步、提前判断效果、少花试错成本、只改不满意的部分，以及得到符合用途的成片。

这一轮最明显的缺口，是已经存在的能力还没有充分围绕创作结果组织。例如，动画标题已经有，但广告里的店名与地址没有自然进入片尾；角色资产已经有，但用户仍要自己维护“这个角色出现在哪些镜头”；成片已经生成，主要按钮仍然邀请用户“先试这一镜”。

**2026-10-17 更新：本报告列出的 B01–B06、X01–X14、N01–N08 共 28 项已完成开发及本地生产验收。** 下文一至八节保留 10 月 16 日的原始观察和改造规格；最新实现、测试及边界见[第九节验收记录](#九2026-10-17-实现与本地生产验收)。

## 一、这轮真实操作与证据边界

证据目录：[本轮浏览器记录](evidence/pm-full-20261016/)。此前 U01–U22 的实现与真实模型验收见 [上一轮交付记录](production-center-ux22-20261016.md)。本轮以当前界面重新观察，不将上一轮的问题原样认定为尚未修复。

| 路径 | 本轮实际操作 | 结论与边界 |
| --- | --- | --- |
| 已完成作品 | 重开 Warm Cafe Morning；查看三镜头、已选用素材与生成入口 | 作品存在、状态可读；完成后的主动作仍偏向再次生成 |

| 用途与模板 | 切换故事影片、产品广告、知识讲解、数字主持人；打开创意模板；两次点击侧栏创作模板，并直接访问模板 URL | 用途说明会变化，但核心输入仍通用；模板入口没有呈现可浏览的模板库 |
| 角色与参考 | 建立“晓岚：咖啡师”；填写描述；选择只应用到镜头二；展开一致性和详细设定 | 能保存并选择范围；没有新增参考图推理；设定结构仍需用户手工维护 |
| 项目工具 | 打开角色、3D 人物与机位、剧本与道具、历史、协作、审阅、助手及其设置 | 已有能力可以找到；本轮没有执行版本回滚、邀请真实协作者或导入新 GLB |
| 十四种素材工具 | 每种表单逐一打开；展开语言与高级参数 | 完成输入与信息组织检查；没有逐一运行十四种模型转换，不能据此宣布所有输出质量通过 |
| 已有素材成片 | 新建第二个独立项目；上传两个示例视频和一段音乐；选中第一片段；修改字幕；配乐调至 20%；打开裁切、速度、转场、标题与特效 | 真实编辑并进入交付；上传后正确允许跳过故事和镜头计划 |
| 导出 | 选 360p；实际下载 MP4；FFprobe 检查；FFmpeg 完整解码 | 成片 **6.021029 秒、640×360、H.264/AAC、701234 字节**；完整解码成功 |
| 审片 | 创建测试审片链接；用无登录的新浏览器上下文打开；读取并播放视频；撤销链接 | 匿名端视频就绪、无媒体错误；管理端显示已撤销。本轮未再次访问撤销后的匿名地址，不扩写为撤销访问控制专项验收；仅为本地 HTTPS |
| 素材库与画布 | 切换素材库、画布；打开添加节点、搜索创建、筛选；检查上传视频；打开免费媒体编辑 | 两种视图能切换；素材库和已上传媒体的心智不统一；上传节点仍突出生成设置 |
| 免费媒体修剪 | 对静音示例视频设置 0.5–2 秒修剪，保存新副本 | 原素材保留，新副本成功；出现与当前修剪无关的“请选择有声音的视频”提示 |
| 改进建议 | 先确认“人物更近”，再打开“环境更多”的确认框；记录后取消第二次修改，并恢复本测试镜头原始输入 | 确认框同时包含近景和更宽景别要求，互斥意图没有替换处理；没有生成新视频 |
| 尺寸适配 | 1366×768、390×844 查看画面页 | 390px 无页面水平溢出，固定底栏存在；顶部重复项目区域占据较多高度 |
| Agent 接入 | 打开接入面板，运行“测试平台连接” | 平台连接测试通过；本轮未启动外部 MCP 客户端，也未给其新增生成授权 |

## 二、所有主要功能应当服务什么任务

“功能齐全”的判定应同时包括：入口找得到、输入看得懂、执行范围准确、结果能采用、失败能恢复、后续步骤能复用。表单存在只能证明其中一部分。

| 功能区域 | 当前能力及本轮观察 | 产品方向 |
| --- | --- | --- |
| 项目管理 | 项目切换、新建、重命名、保存状态、备份与导入入口；多个项目仍叫未命名 | 作品封面、自动建议名称、最近编辑时间、继续当前步骤；备份放项目菜单 |
| 想法输入 | 一段想法、用途、时长、画幅、AI 整理与手动草稿 | 对一句话先识别要求，只补问缺少的关键项，不换成十几个必填字段 |
| 模板 | 简报有创意模板；高级画布有单镜头、角色叙事、产品广告模板 | 主入口提供成片示例、适用用途、需要的素材和预计制作步骤；套用为新项目或草稿 |
| 剧本与分镜 | 镜头顺序、画面、台词、时长；高级剧本、道具、结构化数据 | 增加全片叙事检查，明确开头、主体、结尾；高级结构化输入继续折叠 |
| 角色与场景 | 可复用描述、图像、版本、一致性、范围选择 | 自动整理人物与出现镜头，由用户确认；让每镜实际采用的参考及版本可见 |
| 风格 | 风格资产与文字设定可复用 | 用可视风格卡配合少量示例，避免同片叠加互相冲突的风格描述 |
| 图像生成 | 镜头关键画面、模型与参数、范围确认、上传替代 | 先看整组关键画面，确认风格与人物，再进入视频阶段 |
| 视频生成 | 单镜头试做、模型能力、引用、范围与费用上限、定时 | 用状态决定主动作；明确重用什么、生成什么、哪些参考仅通过首帧传递 |
| 候选版本 | 当前镜头候选、比较、选用、保留原素材 | 将“生成成功”和“用户已选用”分开，替换时说明时间线是否更新 |
| 创作助手 | 当前项目上下文、建议、设置与技能入口 | 默认帮用户完成当前阶段的小任务，展示拟修改内容；模型设置放次级入口 |
| 3D 预演 | 可从镜头打开人物与机位预设，支持更深的导演设置 | 保持可选；用预设图说明效果，不要求所有新手学习相机数值 |
| 素材制作 | 十四种制作/转换工具，已有任务分组 | 当前素材旁按“我想做什么”展示兼容工具，自动带入源素材 |
| 免费媒体处理 | 修剪、提帧、裁剪、尺寸、旋转、速度、倒放、提音频 | 增加拖动入出点和直接预览；无音轨限制只解释提音频，不干扰修剪 |
| 时间线 | 片段排序、裁切、速度、转场、预览与精确参数 | 预览和时间线保持可见，支持边缘裁切、播放头分割，数字仍供精调 |
| 字幕 | 片段字幕和统一字幕编辑已有连接，支持导出相关入口 | 合成一个选中字幕的编辑区，显示来源、时间和安全区；不要重新制造两套字幕 |
| 角色配音 | 音色、台词、角色绑定、试听/制作相关入口 | 对白先决定合理镜头时长；音色一旦确认，后续镜头默认复用 |
| 配乐与音效 | 音频上传、轨道、音量、配乐与音效工具 | 加入“人声优先”混音和简单节拍建议，不让用户靠多次百分比试听猜平衡 |
| 标题与动效 | 已有动画标题、动效模板、预览及导出入口 | 在片尾、知识重点、产品卖点位置主动出现；品牌文字用真实图层保证正确 |
| 审阅与返工 | 时间点意见、审核、局部返工、保留已满意部分 | 将意见变成待办：问题→修改方案→影响镜头→新旧比较→采用或撤回 |
| 质量检查 | 创作流程、素材可播放、预览/导出版本检查 | 补充可操作的声音、字幕、画幅、缺素材检查；创意建议与阻断错误区分 |
| 导出 | 平台、清晰度、画幅适配、高级参数、MP4 与其他交付能力 | 推荐跟随源素材；明确“放大输出尺寸”和“补充真实细节”是不同处理 |
| 审片分享 | 导出后可建链接、匿名观看、撤销 | “给别人看”与“邀请一起编辑”并列，入口文字体现实际用途 |
| 协作 | 账号/ID、角色、保存权限入口 | 普通用户优先从成员身份理解权限，技术 ID 作为备用输入 |
| 历史与恢复 | 自动保存、命名版本、回收等能力已有入口 | 用“分镜确认版 / 配音完成版 / 交付版”辅助命名，让用户理解恢复影响 |
| 任务中心 | 云工作流、本地任务、底层提交尝试 | 先统一项目、类型与状态筛选；技术请求信息折叠为诊断详情 |
| 高级画布 | 文本、剧本、便签、角色、场景、风格、图片、视频、音频、剪辑合成十类节点 | 保留专业能力；从已完成素材进入时优先编辑/复用，而非空提示词与模型 |
| MCP / Skill | 平台连接、配置片段、权限、编辑与生成开关 | 继续服务高级 Agent；统一读写项目状态，生成授权独立；普通新手不需要先配置 |

### 十四种素材工具逐项结论

本轮检查了每种工具的输入界面，以下是交互改进建议，不是十四种输出均已重新验收。

| 工具 | 默认应该怎样使用 | 专业参数放在哪里 |
| --- | --- | --- |
| 角色配音 | 选角色与音色→填/取当前台词→试听→加入对白轨 | 语速、音高、表现力、发音词典 |
| 声音克隆 | 明确授权提示→上传参考音频→样音→保存音色 | 质量、分段、稳定性；无可用服务时直接解释 |
| 音频翻译 | 默认选中当前音轨→目标语言→译文确认→制作 | 保留时长、说话人、音色等实际支持项 |
| 口型同步 | 当前人物视频+对白音轨→范围预览→对齐 | 面部选择、强度、输出规格等实际支持项 |
| 配乐 | 影片情绪、是否有人声、长度→预听→使用 | BPM、种子、段落结构 |
| 音效 | 选事件与时间点，例如“杯子放桌上”→预听 | 环境空间、强度、随机种子 |
| 音轨分离 | 选源音频/视频→选择要保留的人声或伴奏 | 分离模型与输出通道 |
| 去背景 | 当前图或视频→预览主体边缘→输出 | 蒙版修正、边缘羽化；隐藏无关语言字段 |
| 放大 | 当前媒体→目标尺寸→效果比较 | 模型/强度；如仅重采样须明确说明 |
| 扩图 | 选新画幅→拖动主体位置→补边 | 扩展方向、描述、模型参数 |
| 图层分离 | 当前图片→查看分离预览→选择图层 | 层数、合并规则、导出格式 |
| 分镜网格 | 选镜头与统一风格→生成可检查的网格→拆为镜头 | 网格规格、数量、图像参数 |
| 图片转 3D | 当前图片→用途说明→模型预览→使用/导出 | 网格、纹理、格式；继续归入进阶工具 |
| 视频深度参考 | 当前视频→深度预览→用作后续参考 | 分辨率等必要项；不把无关文本或语言显示成必填 |

本地通用工具表单在图像/深度工具中仍显示“语言与高级参数·中文”。应按模型任务能力显示字段，避免把每一种功能都做成“描述+预算+生成”的相同表单。

## 三、确认复现的问题

这里 P0/P1/P2 是产品改造顺序，不是安全漏洞等级。P0 先保证创作意图和主流程，P1 改善关键操作，P2 提高效率与表达准确性。

| 编号 | 优先级 | 真实现象与影响 | 修改要求 | 验收条件 |
| --- | --- | --- | --- | --- |
| B01 | P0 | 单行脚本“镜头一…镜头二…镜头三…整体要求：温暖真实…”把整体要求放进第三镜头 | 编号拆分时识别行内全局要求，保留原文并给拆分预览；不把要求当作镜头 | 中文/英文、换行/单行、不同标点均能分离；角色衣着等约束进入相关镜头，不把结尾要求无差别加到每镜 |
| B02 | P1 | 任务中心“当前项目”仍显示 Warm Cafe Morning 等其他项目的本地任务和底层尝试 | 所有任务来源共用项目/类型过滤；无法归属的尝试标为“未关联”，仅在全部/诊断中显示 | A 项目当前筛选没有 B 项目任务；切换全部可见；无关联记录不会伪装成当前项目 |
| B03 | P1 | 侧栏“创作模板”落回引导工作区，恢复原画面/镜头阶段，未呈现模板浏览 | 入口打开真正模板选择；区分浏览、预览、套用；当前项目套用前显示影响 | 从各阶段点模板均打开模板库；返回原项目位置不丢；取消套用不改分镜 |
| B04 | P1 | 只生成一张 FLUX 图片的确认框写“估算涵盖视频请求”；目录价格 0，却主要展示 $5 上限 | 确认文案按实际任务构成；预计费用与硬上限分别标明，未知价格直说未知 | 图片/视频/音频/混合任务确认单均匹配；零价格不暗示要支付 $5；不通过隐藏确认绕过费用保护 |
| B05 | P1 | 先选“人物更近”再选“环境更多”，修改后并列近景与宽景要求 | 改进意图使用结构化字段；互斥项替换并展示前后变化；自由文字保留 | 连续选择近景→全景只保留最新意图；撤销还原；不静默改角色、音轨或其他镜头 |
| B06 | P2 | 静音视频在修剪界面也提示换有声音的视频，而修剪实际能完成 | 仅在提音频选项说明音轨限制，其余操作显示相关信息 | 静音视频可修剪、提帧、裁剪；提音频禁用有明确原因，不影响其他操作 |

## 四、现有功能的体验优化清单

这些项目主要调整状态、入口、默认值与联动，不需要再复制一套创作工具。

| 编号 / 优先级 | 目前使用成本 | 应改成什么 | 完成验收 |
| --- | --- | --- | --- |
| X01 / P0 | 三镜头均已选用，仍突出“先试这一镜”；已在视频模式仍出现“确认此画面，制作视频” | 待做图→制作关键画面；待视频→制作视频；有候选→比较/采用；已选用→剪辑整片；重做为次级动作 | 各状态主按钮含义、实际执行和确认范围一致；点击已完成作品不会默认再次花费 |
| X02 / P1 | 画面页显示上一项“合成已完成100%”，容易误以为当前镜头刚生成 | 当前镜头状态独立于项目最近任务；其他任务收在任务入口 | 合成、音频、图像任务不会覆盖不相关镜头的进度含义 |
| X03 / P1 | 四种用途的起步字段仍相似，广告卖点、地址、结尾行动提示靠用户自己组织 | 一句话自动提取为少量确认标签，只补缺项；不同用途有不同检查重点 | 广告不遗漏产品/卖点/结尾信息，故事不被要求填商品字段；所有推断可改 |
| X04 / P1 | “素材库”主要显示角色/场景设定；本项目上传视频和音乐在节点中，右侧仍是生成设置 | 同一素材库提供上传、生成、已用、角色场景、成片视图；选什么显示什么操作 | 上传视频能检索、预览、放入时间线并追溯来源；切库不显示不相关生成表单 |
| X05 / P1 | 角色描述、衣着、声音、一致性多层展开；出现镜头要手动选 | 默认一张角色卡展示照片/衣着/声音/出现镜头；高级设定折叠；自动建议关联但由用户确认 | 同一人物复用引用版本；变更衣着时展示受影响镜头；不把主角强加给空镜 |
| X06 / P1 | 工具虽然分组，进入后仍常见通用表单和无关语言设置 | 当前素材上提供任务动作，自动填源素材，只显示兼容字段 | 缺源/不支持/无服务分别解释；从镜头调用不会忘记当前素材和目标轨道 |
| X07 / P1 | 精确编辑以数字为主；用户需滚动查看片段和属性 | 片段边缘裁切、播放头分割、拖动音频/字幕，数值精调留在侧栏 | 鼠标与键盘都能完成；撤销恢复；预览、导出边界一致；触屏提供等价操作 |
| X08 / P1 | 字幕既在片段字段也在统一列表中，选中输入仍有技术标识 | 一个字幕编辑区，按选中字幕定位；显示片段名称与来源，配安全区预览 | 同一次修改反映到预览、统一列表、SRT 和成片；不会重复烧录 |
| X09 / P1 | 动画标题已经有，但藏在扩展项中；广告店名还可能被写进生成提示词 | 结尾信息直接形成可编辑的真实标题/Logo/地址图层，附少量风格模板 | 片尾文字正确、停留足够、横竖版不出界；调整文案不重跑视频模型 |
| X10 / P1 | “整片检查”下面再展开检查清单，核心是流程完成；用户仍不知怎么改善 | 检查结果直接列出可操作事项，区分必须修复与可忽略建议，点击定位 | 缺文件、字幕越界、音轨问题能定位并重查；人工判断不伪装成已由 AI 客观认证 |
| X11 / P1 | “分享项目”先看到协作者账号/ID，给别人看成片的入口在导出 | 一个分享入口先选“给别人看 / 邀请一起编辑”；看成片默认当前交付版本 | 权限、版本、有效期清楚；无成片时提示先导出；复制链接不等于自动通知他人 |
| X12 / P2 | 640×360 源素材默认输出1080p，虽有提醒仍可能被理解为变清晰 | 默认推荐跟随源素材；选1080时解释是否重采样；增强另有明确能力与费用 | 推荐值和实际输出一致；不将单纯扩大尺寸命名为画质修复 |
| X13 / P2 | 项目选择区、未命名项目标题、工作台标题、高级工具行和五步导航叠加 | 项目栏合并名称/保存/菜单；仅保留当前阶段和主要任务，进阶入口集中 | 1366×768 同时看到画面与主动作；390px 无横向溢出、底栏不遮内容 |
| X14 / P2 | 上传视频进入画布仍提示填提示词，右侧以模型和首尾帧为主；专业 Agent 配置也较技术化 | 上传素材默认预览/编辑/加入成片/存入库；生成变体另行展开；Agent 放进阶设置 | 不要求已有素材用户先选模型；Agent 与 UI 使用同一项目和权限，配置入口不占新手主流程 |

## 五、值得新增的八项能力

这里的“新增”指用户目前缺少的完整操作结果。可以复用现有分镜、模型、声音、字幕、标题和版本系统，不应做八个彼此孤立的新页面。

| 编号 / 顺序 | 新能力 | 用户直接得到什么 | 与已有功能衔接及边界 |
| --- | --- | --- | --- |
| N01 / 第一批 | 按作品用途组织的创作配方 | 门店广告、产品展示、角色短片、知识讲解、口播等各有开头/主体/结尾结构及示例 | 复用简报、模板、分镜、标题与音轨；不是仅替换一段提示词；首批聚焦少量高质量配方 |
| N02 / 第一批 | 整组关键画面审阅与轻量分镜预演 | 一眼看全片人物、风格、场景与接镜；先用关键图+临时声音判断节奏，再做视频 | 复用故事板与时间线；与已有3D预演互补；选用和参考版本有记录，不承诺模型百分之百一致 |
| N03 / 第一批 | 对白先行的时长安排 | 先确认台词、试听和合理语速，再推荐镜头时长与切点 | 保留现有配音/字幕/音轨；超长台词给“缩文案 / 加时长 / 拆镜头”选择，不能偷偷加速 |
| N04 / 第一批 | 简单可靠的自动混音 | 开启“人声优先”，说话时音乐降低；尾部淡出；提醒音量突变 | 在现有手动20%音量基础上增加自动压低与规范化；允许关闭；预览与导出使用同一规则 |
| N05 / 第二批 | 基于问题的局部修改方案 | 用户说“第二镜人物变了”，系统列明改参考/改描述/重做哪一镜、保留什么 | 复用当前局部返工与比较；先给可编辑变更单；只改字幕/音量时不走生成 |
| N06 / 第二批 | 可复用品牌与片尾包 | 店名、Logo、主色、字体、地址、行动提示在新项目中直接使用 | 复用真实文字图层；支持横竖版安全区；品牌信息与角色资产职责分开 |
| N07 / 第二批 | 跨画幅的布局适配预览 | 同一作品输出横版、竖版前看到主体裁切、字幕位置和片尾布局 | 基于已有画幅/版本功能补预览、人工确认和规则布局；没有可靠主体识别时提供手动定位，不冒充已自动重构 |
| N08 / 第三批 | 能力真实可用的草稿→正式制作策略 | 用户明确知道草稿便宜在哪、时长和限制是什么，确认方向后再做正式版 | 复用单镜试做、版本与费用确认；只有服务支持真实低成本档才提供；仅缩时长要直说，升分辨率不保证内容完全相同 |

新增质量检查应先用可验证规则处理文件可读、画幅、字幕、安全区、空轨道、明显峰值与版本同步。人物漂移、叙事完整和美感建议需标明判断来源；不能给一个没有校准依据的“影片质量98分”。

## 七、制作流程具体应该怎样变化

### 1. 开始只给三个入口

“描述我要做的视频”“用已有素材剪一条”“从成片示例开始”。高级画布、Agent 接入和专业工具继续可用，但不成为首片必经步骤。

用户输入咖啡店开业广告后，界面先给可改的确认摘要：门店广告、12秒、用于抖音、温暖真实、三镜头、店名地址尚未提供。对“抖音”可建议9:16，但必须显示并允许更改，不能静默修改画幅。

### 2. 五步都只要求一次核心判断

| 阶段 | 用户判断 | 默认内容 | 主要动作 |
| --- | --- | --- | --- |
| 想法 | 我们是否理解你要做的作品？ | 一段想法、用途标签、必要补问、素材上传 | 整理成分镜 |
| 镜头 | 这些画面和台词能讲清楚吗？ | 全片结构、每镜画面/台词/时长、人物出现位置 | 确认分镜 |
| 画面 | 人物、风格和动作是否符合预期？ | 整组关键图、当前镜头、参考版本、试做结果 | 随状态变为制作画面 / 试做视频 / 采用结果 / 继续剪辑 |
| 剪辑与声音 | 节奏、声音和文字是否舒服？ | 整片预览、时间线、当前选中项设置 | 预览整片并检查 |
| 导出 | 这版能否给目标观众看？ | 输出用途、推荐规格、待修事项、当前交付版 | 导出视频；完成后下载或分享 |

主动作在同一时刻应表达同一任务。固定底栏负责执行或继续，右侧设置区调整参数，避免两个同等强调的“先试这一镜”。

### 3. 不满意时按问题修改

例如“第二镜女咖啡师脸变了，其他都保留”：先展示镜头二引用的角色和关键图，建议调整参考或重做关键图；明确将重做的视频及费用；原时间线采用版本暂保留；生成后并排比较；用户采用才更新相应片段。若用户只改店名，直接修改片尾文字图层。

### 4. 不同作品要给不同质量帮助

- 门店/产品广告：开头快速建立对象，明确一个主要卖点，片尾正确显示品牌与行动提示。
- 角色故事：角色身份、服装、空间关系、动作和接镜连续；对白有合理时长。
- 知识讲解：信息准确、层级清楚，字幕与旁白不超载，示意图服务解释。
- 数字口播：台词可读、发音可调、声音和口型对齐，避免只得到一个无结尾的片段。
- 已有素材剪辑：允许直接剪，不强迫补剧本、参考或生成服务；检查重点转为节奏、声音、字幕与交付。

## 八、减少哪些繁杂内容

应减少默认显示和重复操作，保持能力可通过上下文或进阶入口找到。

1. 合并重复的项目名称、项目选择、工作台标题和独立高级工具横条。
2. 主流程不常驻节点 ID、渠道号、HTTP200、提交 UUID、原始 JSON、UTC 时间串；诊断面板继续保留。
3. 不给所有图像/视频工具展示语言、种子和预算等相同表单；按任务和真实能力显示。
4. 合并“分享项目”与交付分享的入口认知，明确观看和编辑两种目的。
5. 合并同一字幕在片段和列表的重复输入，保持同一数据来源。
6. 3D、MCP、Skill、复杂协作和外部连接器保留进阶入口，不成为制作第一条视频的前置条件。
7. 不再叠加另一个制作中心、另一个模板计划或另一个素材副本系统；所有操作复用同一项目、镜头、素材版本与交付版本。

## 九、实施顺序与验收

| 批次 | 范围 | 达成结果 |
| --- | --- | --- |
| 第一批：修正误导与创作意图 | B01–B06、X01–X02 | 输入要求不被误拆，范围不串项目，状态与确认准确，入口承诺兑现 |
| 第二批：让第一条作品更容易完成 | X03–X06、X09、X11、N01–N02 | 用途引导、统一素材、角色关联、分镜审阅、片尾与分享串起来 |
| 第三批：提升声音、剪辑和返工质量 | X07–X08、X10、N03–N05 | 先对齐台词时长，再做混音；问题定位、局部修改、比较采用闭环 |
| 第四批：复用与进阶效率 | X12–X14、N06–N08 | 品牌复用、跨画幅、草稿策略、高级入口持续简化 |

每批均需要真实操作验收，不能仅以按钮渲染或单元测试数量为完成条件。至少覆盖以下组合：

1. **12秒门店广告**：一句话→用途确认→三镜头→角色只出现在正确镜头→关键图审阅→试做→批量→对白/音乐/片尾→竖版导出。检查店名地址真实文字、字幕安全区、费用范围。
2. **带对白的角色故事**：两角色不同声音→试听→镜头时长→参考固定→配音/口型按能力接入→整片预览；过长对白有明确处理选择。
3. **零生成剪辑**：新建→上传→裁切/排序→字幕→音乐→导出→匿名审片；全过程不创建用户 API Key、不调用生成模型。
4. **只改第三镜头**：时间点意见→变更方案→费用确认→新旧比较→采用；前两镜、原音轨和未修改字幕不变；可撤回。
5. **恢复与失败**：保存后关闭浏览器重开；生成失败/额度不足/服务不支持/无音轨/上传失败都给可理解的恢复动作；恢复不会重复付费提交。
6. **项目与权限组合**：A/B项目切换与任务过滤；观看链接与协作权限分开；UI和Agent的编辑、生成范围相同；链接创建、过期、撤销均单独验证。
7. **桌面与手机**：1366×768及390px下完成选择、确认、返工、字幕修改、导出；主动作可见，不用横向滚动寻找。
8. **模板与比例变体**：预览/取消模板不改原项目；套用为副本；横竖版不丢主体、字幕、品牌信息；源素材不因导出覆盖。

还应安排真实新手试用，记录第一次有效预览所需时间、无协助完成比例、误触再次生成次数、返工保留率、用户能否解释费用。以上指标目前没有新手样本数据，不编造成“已经提升多少”。作品美感则通过盲看对比、目标观众反馈和明确创作用途评估。

## 十、交付与清理说明
