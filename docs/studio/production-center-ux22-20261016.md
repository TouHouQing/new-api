# 制作中心 22 项体验改版与验收

日期：2026-10-16，Asia/Shanghai。范围对应 [产品复体验中的 U01–U22](production-center-product-review-20261015.md)，本地生产入口为 https://localhost:13443/studio 。

制作中心改为同一个项目中的五步工作区：**想法 → 镜头 → 画面 → 剪辑与声音 → 导出**。旧制作入口定位到相应阶段，专业工具在侧栏打开。原有项目、素材、版本和工作流继续使用。

## 真实制作与返工

独立测试项目 `a1435442-8281-42f4-8250-abb589e07121` 使用本机模型：Qwen3.5-9B 整理分镜、FLUX.2 Klein 4B 制作画面、Wan 2.2 TI2V 5B 制作视频。所有实际请求经平台服务执行，没有伪造任务成功或用固定样片充当模型生成。

实际完成文本规划、角色和场景参考、三张关键画面、三个视频、字幕、配乐、整片预览和 MP4 导出。视频素材实际时长约 2.04 秒一镜，整片导出约 **6.15 秒、640×360、H.264/AAC**，完整解码通过。字幕为“慢一点，生活会更香。”，音乐音量为 20%。

随后只修改第三镜头的景别方向并重新生成。新的第三镜头保留两版候选；第一、第二镜头的生成数据、时间线及音轨与返工前逐项一致。候选可并排播放、切回旧版及重新选用新版，再导出新成片；旧成片继续保留。返工前后成片均完整解码通过，解码后的音频 SHA-256 完全相同。

另用零生成额度的账号建立独立上传项目 `48074678-7ea5-4f74-83e1-af4383fc8814`：上传示例视频和音乐，修改字幕和音量，直接导出 **6.02 秒、640×360、H.264/AAC** 文件。该路径没有运行生成模型。

真实模型用量记录为零，生成前后原账号 Key 数量未增加。当前实现仍要求用户登录，并保留预算、存储、角色和模型权限校验。

## 本轮额外发现并修复的缺陷

1. **隐式参考任务未出现在确认范围中。** 前端执行范围现在包含 `linkedAssetId` 对应的角色、场景等生成依赖，与后端使用一致的依赖计划规则。
2. **系统自己生成参考图，被当作用户并发改动。** 原来目标图有候选但未选用。后端比较冻结输入前，会先应用本任务已提交的依赖结果；用户并发修改的优先权仍保留。回归分别覆盖正常生成与同时修改提示词。
3. **已有一个候选却无法进入审核。** 单个完成候选也可查看和选用，无需重新生成。
4. **模型返回 null 或时长超出目标。** 先规范可选字段，保留用户明确镜头描述，再按目标时长分配。
5. **切换选用版本后，对比区可能只显示一个候选。** 对比对象必须与当前选用版本不同，切换时保留上一版为对照；单候选不展示空的对比下拉框。
