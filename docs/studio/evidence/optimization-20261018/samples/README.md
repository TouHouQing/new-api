复制工程会校验每个素材的字节数和 SHA256，建立新的素材与项目 ID，同时重映射历史提交参考；按账号保存导入进度，失败或刷新后可继续。实际六类工程已通过当前严格 schema 和完整素材复制测试。上传 HTTP、账号权限及生产浏览器试用由主任务统一验收。

## 十一个视觉预设

`web/public/studio-presets/manifest.json` 保留已有真实图片来源，并增加视频。

八项 Wan 实测演示通过本次具体短镜头审看：推近、固定、短侧跟、柔光、轮廓光、商品灯光、水彩、自然电影风格。短侧跟仍有构图漂移，提示词运镜不承诺精确三维路径。每项都查看了全部 49 帧联系表。

环绕、尘埃、雨景的真实 Wan 输出未通过。环绕在最终 1280×704 / 17 帧对照中仍有转形和重影。三项提供原创三维几何或确定粒子合成示意解释意图，并在详情保留实际失败模型视频；示意不会认证模型效果。

最初 384×224 视频出现首帧正常、后续色块。共享一次去噪的完整解码与分块解码对照、禁用动态显存后对照均复现；640×384 消除了该样例的整片条纹。复杂运动的模型质量仍按真实结果逐项记录。

## 修复及证据

口播实测发现单人被 Haar 同时框出面部和颈部，置信度分别为 9.55、2.06。修复按置信度合并满足空间条件的重复框，继续拒绝分离或模糊重叠的多张脸。五项独立回归通过；真实新任务 `audio-2dc7d8e8c1c04da6a336fc2670dc5d63` 完成全部 49 帧，旧失败回执仍保留。

主要文件位于 `wan640-v2/`：

- `reviews.json`：人工逐项审看结论、源文件与成片哈希。
- `installed-verification.json`：六影片及十四个预设/失败详情视频的实际媒体信息、完整解码与哈希检查。
- `root-evidence-handoff.json`：可供主任务安装的文件、URL、SHA256、实际配置及审看范围。
- `*-workflow.json`：真实 Comfy 图、实际种子、步数、帧数及执行状态。
- `*-film-asr.json`：最终成片混音的真实离线转写。

能力证据仍须由主任务绑定当前运行配置的 `configurationDigest` 并复制实际对应字节。此目录没有伪填未知配置摘要，也没有把任务完成状态当作画面效果合格。
