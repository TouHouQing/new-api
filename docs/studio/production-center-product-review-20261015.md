# 制作中心产品复体验与改版方案

日期：2026-10-15，Asia/Shanghai。对象：本地生产版 Studio；对照 LibTV、小云雀、TapNow、即梦。

建议把制作中心升级为常驻的项目工作区，统一成「想法 → 镜头 → 画面 → 剪辑与声音 → 导出」五步。左侧选镜头，中间看画面，右侧修改当前镜头，底部预览整片。高级画布、工具箱、角色与场景、版本、协作继续服务这一个项目。

核心产品目标：用户不用理解节点、连线和模型协议，能够看懂下一步、判断生成结果、只修改不满意的部分，并导出有明确用途的作品。

## 2. 当前最值得保留的基础

现有项目已经具备草稿保存、结构化镜头、参考资产、候选版本、任务范围与费用上限、剪辑、音轨、字幕、审片、版本恢复、协作和导出。免费编辑示例也确实能完成一次交付。

这些能力应继续复用。改版主要调整信息组织、操作位置、默认值和阶段衔接；需要新增的重点能力是更好的创作引导、画面比较、修改影响确认和可操作的质量建议。

## 3. 本轮确认的主要体验问题

下表的 P0 表示优先解决的产品主流程问题；不是对安全漏洞或后端故障的分级。多数问题属于交互与信息架构，不能把它们统称为代码 bug。

| 编号 / 优先级 | 现场表现 | 对用户的影响 | 具体改法 |
| --- | --- | --- | --- |
| U01 / P0 | 主页面五步，制作中心弹窗四步；同项目对应步骤名称不同 | 不清楚两套流程哪个是入口，返回后难以定位 | 合并为一套五步工作区，旧入口定位到同一步；URL、选中镜头和阶段共享 |
| U02 / P0 | 制作中心是长表单弹窗；故事页首屏放了项目管理、检查清单、参考分析、目标时长和简报，只能看到第一个镜头的一部分 | 用户难以同时查看整个镜头结构和实际画面 | 改成全页工作区；项目级信息收在顶部，镜头列表和预览常驻 |
| U03 / P0 | 生成页首屏主要是服务与费用说明，镜头内容在下面；底部「下一步」比实际生成动作更容易发现 | 不知道是否已经开始生成，也看不到要生成的画面 | 当前镜头与预览优先；固定显示一个明确主动作，例如「生成这个镜头」 |
| U04 / P0 | 故事起步主动作有「制作手动镜头草稿」，AI 帮助藏在创作助手里 | 新手仍要自己安排专业制作过程 | 主动作「帮我整理分镜」；展示文本任务的范围和费用后执行；「自己编写」作为并列轻入口 |
| U05 / P0 | 输入包含镜头一、二、三，手动草稿将开头目标、三个镜头合并句、整体要求分别拆成三个镜头 | 后续图片和视频可能围绕错误内容制作 | 明确识别镜头标号、对白和全局要求；手动拆分也要给可编辑预览，不能把要求当画面 |
| U06 / P0 | 「管理角色和场景参考」离开镜头页进入全局素材库；「应用到全部分镜」是显著入口 | 新手需要理解资产与镜头关系，也容易把女主套到咖啡特写 | 当前镜头右侧直接选择或新建角色；列出出现镜头，默认只应用到当前镜头；批量应用需选范围 |
| U07 / P1 | 角色描述、一致性、详细设定等分散为多组字段 | 重复描述，不能直观看到实际使用的是哪张图、哪个版本 | 角色卡默认只显示名称、参考图、服装、声音；细节展开；每镜显示引用版本与用途 |
| U08 / P0 | 生成以「图片 / 视频」勾选项和节点范围为核心，缺少画面到视频的清晰阶段 | 不理解先做图还是直接做视频，也不清楚依赖会额外生成什么 | 镜头卡显示「画面待确认 / 视频待制作 / 已选用」；默认先确认关键画面，再制作视频；依赖任务写进确认单 |
| U09 / P0 | 同一项目从引导进入弹窗后，生成选择是另一套界面状态；本次示例已有上传视频，进入弹窗仍落在生成页，并提示补模型 | 已经有素材的人误以为还要再生成；用户必须重新确认自己的位置 | 选中镜头、执行范围、工具草稿统一；上传素材显示「直接剪辑」；默认生成范围排除上传节点 |
| U10 / P1 | 本地模型零价格，仍显著显示 $5 预算、余额及多段服务说明 | 容易把费用上限当成本次价格，产生不必要的顾虑 | 先显示「本次预计费用 / 本次最多花费」；本地显示明确的零价格；估价未知直接说明；账户余额移到费用详情 |
| U11 / P1 | 「准备快速试片」「先试第一个镜头」「生成选中的素材」意义接近，实际动作不同；快速试片明细显示 3 秒而镜头计划为 4 秒 | 不清楚按钮是设置参数、选择范围还是执行 | 合并为「先试这一镜」一张确认单，明确试片时长；点击确认才执行；正式制作另有范围摘要 |
| U12 / P0 | 「预览、比较与编辑」实际切换到高级画布与连线属性 | 原本只想看画面或换版本，却进入另一套操作方式 | 预览、比较、选用和小修改都在镜头工作区完成；「在高级画布中打开」独立列出 |
| U13 / P1 | 画面建议以统一段落呈现，缺少与当前镜头问题的直接关联 | 用户知道“不好看”，仍不知道下一次该改什么 | 按人物、动作、构图、节奏等给具体建议，显示修改前后内容；用户确认后只修改对应项 |
| U14 / P1 | 创作助手展开后先看到范围、规划模型、任务搜索、技能、预算、导入文件等配置 | 对话入口也像一张管理表单，挤走当前制作画面 | 助手放侧栏，默认只保留输入、当前镜头上下文和建议；模型、技能导入与预算放设置中 |
| U15 / P1 | 十四种素材工具都放在同一个长下拉菜单，音乐默认展开 BPM、种子、语言等 | 找功能要先知道工具名，生成一段配乐也要理解多个参数 | 用「加配音 / 加音乐 / 修改图片 / 修改视频」任务入口；按当前素材显示可用工具，专业参数按需展开 |
| U16 / P1 | 角色配音同时显示声音库、角色绑定、对白导入、语速、音高、静音、表现力等；本次中文界面输出语言默认为英文 | 新手难以知道先选音色还是先填台词，也可能忽略语言 | 默认流程「选角色与音色 → 台词 → 试听 → 使用」；语言随台词检测并可改；音高等放高级设置 |
| U17 / P1 | 选择时间线片段后出现多组数字表单，用户要在预览、时间线和下方属性间滚动 | 修改字幕、裁切和音量时失去对画面的即时判断 | 保持预览与时间线固定；右侧只显示选中项常用属性；拖拽裁切和音量百分比优先 |
| U18 / P1 | 示例字幕在片段里；「逐句编辑字幕」为空且导出 SRT 禁用，没有解释两者关系 | 以为字幕没有保存，或者不知道要在哪一处修改 | 合并字幕视图，显示片段字幕和识别字幕的来源；统一时间轴、预览和 SRT 导出 |
| U19 / P1 | 导出前常驻宽、高、帧率、适配方式、审片选项；主按钮叫「合成交付包」 | 不理解是否要先制作一个“包”，以及哪个按钮是下载视频 | 默认平台 / 横竖版 / 清晰度，主按钮「导出视频」；完成后下载，ZIP 和专业参数放更多选项 |
| U20 / P1 | 审片既出现在导出页，也单独占用高级页签；检查清单和多个质量入口并列 | “检查”“审核”“导出”边界难懂，完成状态不统一 | 整片检查作为导出前一段；团队审阅放预览侧栏；时间点反馈进入同一份修改清单 |
| U21 / P2 | 普通项目仍显示「制作你的第一个视频」；版本页在自动保存列表后直接出现「已删除项目」 | 像一直停留在新手教程，空的回收内容也会被误读 | 项目名与当前任务作为标题；首次提示完成后退出；回收站单独入口并提供清楚空状态 |
| U22 / P1 | 3D 预演先要求相机角度、俯仰、距离等数值，输出目标叫「目标画布节点」 | 不懂摄影术语的人无法判断该怎么用它提高画面 | 在镜头里提供「摆一下人物与机位」，先选择正面、侧面、推近等可视预设；默认回填当前镜头参考 |

## 5. 制作中心应该是什么样

### 页面骨架

顶部只保留项目名称、保存状态、五个制作阶段、任务状态和导出入口。默认不再用弹窗承载整个制作过程。

桌面布局：左侧镜头列表约 220–260px，中间给画面和整片预览，右侧当前镜头设置约 300–340px；剪辑时底部展开时间线。1366×768 下仍需同时看到当前画面与主要动作。窄屏把镜头列表收为抽屉，默认保留预览和主要动作，选中内容及阶段不丢失。

中间预览始终注明对象：「当前镜头」或「整片预览」。修改意见同时绑定镜头、素材版本和时间点，避免用户在整片 12 秒和某镜头第 2 秒之间混淆。

右侧默认只展示当前任务必要字段。角色、场景、声音、工具、历史都可在侧栏打开，不更换项目和工作区。高级画布是同一项目的另一种视图。

### 五步与主动作

| 阶段 | 用户要回答的问题 | 默认可见内容 | 主动作与完成标志 |
| --- | --- | --- | --- |
| 1 想法 | 我想做什么给谁看？ | 一段想法或上传素材；用途、时长、横竖版；可选择完整模板 | 「帮我整理分镜」；返回可编辑草稿，不自动生成图片或视频 |
| 2 镜头 | 这几个画面能把故事说清楚吗？ | 镜头顺序、画面、台词、时长；角色与场景标签；全片时长 | 「确认镜头，准备画面」；明确哪些镜头计划已确认 |
| 3 画面 | 人物和构图满意吗，运动符合预期吗？ | 大预览、画面或视频切换、候选对比、当前参考、一个主要动作 | 「先试这一镜」或「生成这个镜头」；用户选用具体版本后显示「已选用」 |
| 4 剪辑与声音 | 连起来好看吗，声音清楚吗？ | 整片预览；视频、配音、音乐、字幕轨；选中片段常用属性 | 「预览整片」；字幕、音轨、镜头顺序按同一版本同步 |
| 5 导出 | 能按我要的平台规格发布吗？ | 整片检查、平台 / 清晰度 / 画幅、成片预览；问题的修改入口 | 「导出视频」；显示导出版本、可播放成片、下载与继续修改 |

只有素材上传的用户可以直接进入剪辑；不强制补故事、角色或模型。短剧、商品、口播、MV 使用相同骨架，根据用途改变建议和默认设置。

主按钮必须说清动作。选范围、改参数、创建草稿、开始模型生成和下载文件分别使用明确文字；不能再让「下一步」代替当前阶段的关键动作。用户仍可自由切换阶段，缺少内容时就在原处显示需要补什么。

## 6. 如何帮助用户做出更好的作品

### 在花视频生成成本前减少方向错误

首次只要求一句想法，系统整理出一个可编辑方案：主题、开头、发展、收尾、预计时长和参考需求。可选比较不同创意方向，但默认不批量生成多个方案。

故事拆分要尊重镜头标号；全局人物、服装和风格要求单独保存。时长分配结合对白长度、动作复杂度和节奏，不默认把所有镜头平均分配。超过当前模型可用时长时，建议拆镜并让用户确认。

制作视频前先确认关键画面。用户能选择「先做画面」「使用我已有的图片」或模型支持的「直接生成视频」。试片优先选最能验证人物或动作的镜头，默认建议可以更改，不固定只试第一镜。

### 让视觉选择可看、可解释

镜头卡默认显示画面、动作、时长、角色、场景和状态。用可视例子解释「人物更近 / 环境更多」「镜头不动 / 缓慢靠近 / 跟着人物移动」。专业景别、摄影参数和提示词保持可展开。

角色卡关联脸部参考、服装、声音和版本。每张参考图说明用途：人物外观、构图、场景、风格或动作。当前模型只能接收一张首帧时，明确说明并提供制作合成参考的路径；不能把多张引用都展示为已被模型实际使用。

两次生成可以并排比较或同步播放，显示哪些输入发生了变化。用户选用某版后，画布、镜头表和时间线引用同一素材身份；已剪片段切换版本前展示裁切、字幕和音频的影响。

### 让返工成为一次局部操作

选中镜头后可说「只把这一镜改近一点」「人物脸部需要修正」「只换旁白」。先显示修改预览：受影响镜头、会生成什么、预计费用、需要更新的时间线片段。保留用户确认过的字段和版本。

支持问题快捷入口：人物变化、动作太复杂、主体被裁切、节奏拖沓、台词超时、字幕遮脸、背景音乐盖过人声。每个入口对应可编辑建议或具体工具。算法只能提供其能判断的依据，人工仍决定美感和叙事。

### 声音与节奏跟着故事走

对白跟角色与镜头关联。先选音色并试听，再制作正式配音。配音长度变化时提供延长镜头、调整语速、精简台词三种选择，不默默裁掉台词或拉长画面。

音乐默认按全片长度准备，提供情绪和强弱选择；人声出现时可降低音乐，显示百分比音量。MV 按音乐段落和重拍建议切点；剧情片提供建立场景、主体动作、细节与反应镜头的搭配建议。

### 把检查变成能处理的问题

技术检查关注缺素材、不可播放、空白段、字幕越界、音频超长、画幅裁切等；创作建议关注镜头重复、动作负担、对白节奏和人物一致风险。分别说明依据、适用范围和修改入口。

没有片段或文件无法解码时阻止正式导出。审美建议和非必需配音允许忽略；静音短片、上传剪辑和个人项目不强制走团队审核。导出成功后修改项目，应明确显示「当前修改尚未导出」，旧成片继续可访问。

## 7. 完整功能应该放在哪里

| 现有能力 | 改版后的入口与默认行为 |
| --- | --- |
| 故事、剧本、分镜表 | 想法和镜头两个阶段共享草稿；确认应用作为明确提交；原始 JSON 放高级菜单 |
| 文本、图片、视频和音频节点 | 镜头制作时自动建立关系；高级画布保留手动节点与连线 |
| 角色、场景、道具、风格与参考版本 | 项目侧栏；镜头中可直接选择、新建和查看使用范围 |
| 生成、预算、暂停、继续、重试、核对和定时 | 镜头状态与全局任务抽屉；确认单管理实际执行；定时放更多选项 |
| Take、重用、上传、下载和素材库 | 用户看到「候选版本 / 已选用」；上传视为已有素材；下载在预览工具中 |
| 音乐与音效 | 剪辑页「加音乐 / 加音效」；默认匹配片长、情绪与音量，BPM 与种子收起 |
| 角色配音与声音克隆 | 角色声音卡或剪辑页「加配音」；自定义声音只在用户主动选择时进入 |
| 口型同步、翻译配音、音轨分离 | 选中含人物或声音的素材后显示；说明输入要求、语言、范围和模型可用性 |
| 去背景、放大、扩图、图层分离、分镜网格 | 当前图片旁「修改图片」；处理完返回新候选版本 |
| 图片生成 3D、视频深度参考 | 当前素材的更多工具；说明用途与接下来的引用方式 |
| 3D 导演预演、机位与关键帧 | 当前镜头「摆人物与机位」；简单预设优先，完整 3D 控制在高级编辑中 |
| 顺序、裁切、速度、分割、转场、淡入淡出 | 剪辑时间线；常用拖拽可完成，数值精调仍保留 |
| 字幕识别、逐句编辑、SRT 和字幕样式 | 同一字幕轨与字幕侧栏；片段字幕、识别结果统一显示来源 |
| 质量检测、审片、时间点意见与返工 | 整片预览的检查与意见侧栏；回到确切镜头或时间点 |
| 平台输出、画幅、清晰度、水印、MP4、ZIP、专业导出 | 导出面板；MP4 主入口；字幕、素材包及 EDL 等在更多下载选项 |
| 分享、权限、协作者、撤销和到期 | 项目右上「分享」；显示是预览链接还是项目编辑权限 |
| 版本、快照、恢复和项目回收 | 项目历史；恢复前说明影响和保留方式；不混在制作步骤里 |
| 剧集、多地区交付和外部连接 | 项目设置或导出扩展；按真实项目需求使用 |
| 创作助手、MCP 和 Skill | 助手按当前步骤推荐任务；外部 Agent 连接与技能导入放设置。与手动界面使用同一项目、范围、任务和版本 |

保留所有已有能力的可达入口，不要求每个人都先看到所有入口。工具不可用时说明缺少什么，并提供上传或其他可行路径；不做能点但无法完成的主流程入口。

## 8. 实施顺序与验收

| 顺序 | 实施内容 | 必须完成的验收 |
| --- | --- | --- |
| 第一批：统一制作主线 | 合并五步 / 四步；全页镜头工作区；预览不跳画布；共享选中镜头与范围；修正上传项目默认入口和按钮命名 | 从任一旧入口进入都定位同一项目阶段；选中第 3 镜后返回不丢失；上传视频不要求生成模型；1366×768 可见预览与主动作 |
| 第二批：起步与出片质量 | 可靠的镜头拆分；AI 整理入口；角色和参考侧栏；画面确认、试片确认和候选比较；局部修改影响预览 | 咖啡馆例子生成三个正确草稿，整体要求不变成镜头；只改第 3 镜时其余镜头及音轨保持；当前模型不支持的参考不冒充生效 |
| 第三批：声音、精修与交付 | 简化音色 / 配音 / 音乐流程；字幕统一；固定预览与时间线；导出预设；检查和返工整合；高级工具按素材出现 | 修改字幕无需重新生成视频；更换声音不会重做画面；完整 MP4 声画字幕一致；改动后旧导出有版本说明；分享权限和撤销仍可用 |

上述三批构成完整改版范围。第一批完成只代表主线入口改善，不能称整套改版完成。

建议用以下真实任务判断是否易用，而不是按新增按钮数验收：

1. 第一次使用的人只提供一句想法，能明确理解草稿与实际生成的区别，完成一个三镜头短片。
2. 上传自己的视频，改一句字幕、加配乐，直接导出，不接触模型配置。
3. 只把第三个镜头改为近景，其他已满意素材、配音、字幕和剪辑点能够保留并追溯。
4. 人物 / 商品参考不足或模型不支持时，在提交前知道问题以及可行替代办法。
5. 中断或失败后重新打开项目，能看到真实状态、已完成结果和下一步补救，避免重复生成。
6. 连续预览整片后，以发布平台规格导出并在播放器重新打开检查；交付版本可与素材版本对应。

可用性验证应邀请至少 5 位没有 AI 视频经验的人，不在旁边提示。记录完成率、停顿与误点、第一次找到主动作的时间、为改一个镜头切换的页面数、以及对费用的理解。本轮为单人产品复体验，尚未取得这些用户数据；不填写虚构满意度或效率提升比例。
