# 标题与图形叠层

剪辑的文字工具提供标题、图标、形状和图片叠层。添加后进入检查面板，可修改位置、大小、字体、颜色和动画；也可在预览中拖动，用方向键移动1%、Shift加方向键移动5%。一次拖动只进入一次撤销历史。文字修改先应用或放弃，未处理的草稿会阻止切换片段、面板或启动新导出。锁定轨道阻止修改。

叠层属于 `kind:text` 的具体时间线片段，完整设定保存在 `graphic`。它不能携带字幕外观或字幕跟随字段。`kind` 支持text/icon/shape/image；`animation` 支持none/fade/slide/pulse/bounce/rotate/morph，morph仅适用于shape；字体为sans/serif。`size` 是12至300的成片像素，位置x/y为0至1，颜色为六位十六进制。图片仅引用本人就绪资源，不接受任意URL。图片、PNG预览和生成成片分别受原生所有权及大小限制。

动画使用片段源时间：节目时间减片段起点，再加 `sourceStartMs` 和 `phaseOffsetMs`。拆分、裁剪和移动保留原节奏；明确选择重新覆盖片段或 `setGraphic.restart:true` 才重置源时间与动画长度。时间线靠上的轨道覆盖下方轨道，相同顺序保留片段文档顺序；字幕重点位于自己的文字底层之后。

`POST /projects/:id/timeline/graphic-preview` 在内存中返回原生PNG和图层几何。页面与FFmpeg复用同一字体和栅格，按同一公式在节目时钟采样。预览请求最多512KiB、128个叠层，响应PNG总量最多6MiB，像素预算4800万。此接口不创建模型任务或素材文件。

图片合成前会把ICC或PNG gamma／色度定义转换为sRGB像素，保留未预乘的透明度；原图片文件及其描述文件不修改。已独立对照P3、灰度和线性gamma样例；不能读取的ICC或HDR色彩配置会明确报错，需要先转换后使用，不能静默丢弃配置。

纯标题或图形作品可以通过原生FFmpeg导出，使用正常的固定快照、任务回执和重开恢复。浏览器基础离线合成不承担这些叠层，界面会明确引导使用成片导出。生成模型和个人API Key都不参与此流程。

## 旧工程迁移

原生转换器从v4起在新独立剪辑中转换 `production.motionGraphics`；v5继续接入素材分析历史。区域转换器v2转换该区域自己的动效，使用原始图片、字体、位置、节目起止和动画相位。旧主转换及v1区域转换的历史正文、元数据和任务不改写。新增转换复用已有文字稿来源及历史，保留人工最新修订、标题和归档状态；来源历史冲突会让整个事务失败。

旧工程版本入口优先显示已有v2转换，缺少v2时继续展示此前的v1版本。只有旧版包含动效时才额外提供「更新为可编辑动效」；查看旧版保留原文和原素材，不隐式创建新版本或覆盖历史。

字段结构未知、时间无法表达、数量超限等情况仍在转换报告中明确保留原文；图片缺失会阻止转换。已归档不代表已转换，未转换字段仍阻止把旧版直接作为完整交付导出。

## Agent 接口

网页命令与MCP均支持 `addGraphic` / `setGraphic`。MCP使用已有timeline edits预览、明确确认、CAS和完成回执，图片资源继续验证归属；重放不会重复修改。新增对象需要未使用的唯一编号，修改已有对象必须使用读取到的编号。完整请求及响应见OpenAPI；使用说明见MCP Skill。
