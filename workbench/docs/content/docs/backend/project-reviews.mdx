审片由影策原生项目、资源、任务和存储配额承载。它固定具体文件与实际 SHA256，后续换候选、切换角色主版本或继续剪辑不会改写旧原片。本轮在本地主环境与独立恢复实例中完成页面、文件和权限验收；整套合并的其他领域继续按保留矩阵验收。

## 制作流程

在镜头候选、已完成的固定剪辑导出或项目资产预览中选择送审。资产须选择具体版本的媒体表现；成片须同时对应剪辑 ID、摘要和成功导出任务。创建时完整读取原文件校验 SHA，不重复复制媒体，不启动生成任务。

意见可以针对整片、具体时间点、时间范围或准确片段。重复素材实例分别保留 clipId，变速后的意见按固定时钟映射回原片。不能把旧版意见挂到后来选中的文件上。图片不接受视频时间。

需要修改的问题使审片进入 `changes_requested`，未处理时不能通过。处理方式为关联实际变化的后续审片、不采纳并说明原因，或仅将普通建议标为已阅。修复版创建时关联上一轮审片；最终在新一轮检查实际原片并提交结论。已有后续复审时，不会将旧原片误标为最终通过。需要重新检查同一文件时，使用原审片 snapshot 创建新一轮，不追随后来更换的资产表现。

## 权限与分享

项目所有者可给已有账号授予 `reviewer` 或 `viewer`，并可撤销。审片者可留言、认领和提交结论；查看者只读。制作协作者的审片权限与普通项目编辑 API 的权限分别校验，不能将审片授权声称为完整项目编辑授权。成员变更与审片写操作锁定同一项目，事务内重新检查账号、所有者、项目和授权状态。

只有所有者可创建和撤销分享链接。链接固定本轮原片，有效期为1至30天，可以仅查看或允许访客建议。访客不能改项目、指派、审批、上传或伪造阻断问题。称呼是访客自填，不代表已验证账号。

链接为 `/review/<分享ID>#token=<凭据>`。片段凭据通过 JSON POST 换取 HttpOnly、Secure、SameSiteStrict 且限定 `/api/review-shares/<分享ID>` 路径的 Cookie；URL 查询参数不携带凭据。每次读取、播放与留言都重新校验链接、所有者、项目与原片状态。流式媒体支持 Range，使用 private no-store，不返回可复用存储链接。撤销、到期、归档或停用所有者后拒绝后续请求。归档恢复不重新激活旧链接。

## 接口与恢复

具体请求见 `/api/openapi.yaml`。已登录操作通过 `/reviews`、`/projects/:id/reviews`、`/projects/:id/members`、意见及分享子路径调用；公开访客只使用 `/review-shares/:shareId` 的限定接口。

所有审片写操作使用稳定 requestId；意见和状态修改还要求准确 revision。服务端回执与业务修改原子提交，旧回执不会覆盖后来意见、恢复权限或激活旧链接。网页先保存账号隔离的操作意图，响应丢失后按原编号核对。访客留言同样保留稳定编号；明确拒绝且确认没有回执时允许修改重试，未知回复保留原意图。

数据库 Schema 68 增加五张原生表，详情见数据库文档。原片纳入删除保护；审片正文、意见、回执及分享密文计入原有结构化配额。共享者不能绕过所有者的资源配额。链接原始凭据不进入回执正文或公开模型。

MCP 的审片、意见、返工定位、协作者与分享工具调用相同接口，写操作要求明确确认；随附 Skill 说明固定来源与恢复规则。创建链接只返回结果，不自动向外发消息。

## 本地验收范围

两环境共60项实际页面检查，覆盖固定导出送审、草稿刷新、未知回复恢复、多账号拒绝、重复素材和变速定位、访客意见、撤销、图片换版保护、真实视频与音频播放、返工字幕和复审。新旧成片各自解码并检查文件摘要、字幕变化和音频一致性。升级后的125张表及482个文件通过独立恢复；五张审片表与主库逐项一致，恢复后再次核对历史成片、指派、修复关联、重复回执和访问撤销。

本轮保留了201项原生专项、2850项网页回归、35项MCP检查、Skill校验与生产构建的证据。二级测试账号使用明确标注的临时原生会话夹具，未将其声称为二级账号注册或密码登录验收。校准媒体不能证明生成模型质量。完整项目编辑授权与旧工程审片迁移仍未验收，不能把审片协作权限当成其完成证明。
