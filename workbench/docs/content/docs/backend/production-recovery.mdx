title: 生成与成片恢复
description: 核对原生成请求，以及在新浏览器中找回项目已有成片。
---

## 分镜生成提交中断

分镜图、动作预演和镜头视频在调用模型前，先在当前账号的浏览器存储中保存原请求、镜头版本和操作编号。请求包括实际提示词、参考资源和模型参数；渠道凭据只保存摘要，重试时从原渠道配置读取并校验。

如果提交响应中断，工作区显示“先核对上次提交”。“查询原任务”只查询原操作编号；“按原参数重试”先查询，确实未找到才提交同一编号、同一参数。修改当前表单不会改写原请求。明确拒绝且未建立任务的提交可以重新编辑；无法确认的提交保留原记录，不能直接创建新生成。

重新打开同一浏览器可继续核对。已接受的任务保存在服务端，换设备可通过任务记录读取；尚未接受的浏览器记录不会同步到其他设备。清除浏览器数据会丢失这部分本地记录。账号切换、记录损坏、无法持久化或原凭据变化时，界面给出错误，不能静默重发。

## 单张素材制作视频

视频模型只支持图生视频、且镜头仅绑定一张图片时，工作台将该图片作为首帧，并在“画面来源”说明中展示这一点。支持全模态参考的模型继续使用资产参考方式。多图或带声音的资产不会被自动缩减成单图；必须按模型能力调整绑定或选择支持的模型。

## 项目已有成片

剪辑器的“导出”面板提供“已有成片与导出记录”。记录来自当前项目的持久任务，支持翻页、刷新、预览和下载，并显示其固定剪辑版本。新浏览器无需先找到自动恢复版本，也无需重新渲染。

查看已有结果只读取任务和资源。失败、取消、进行中的任务保留实际状态；失效文件不会显示成可用成片。要生成当前剪辑的新结果，使用下方独立的导出按钮。已有文件不会随当前剪辑修改而变化。

这些恢复功能不能替代作品质量审核。模型任务成功、资源可读、声音画面质量合格需要分别检查。
