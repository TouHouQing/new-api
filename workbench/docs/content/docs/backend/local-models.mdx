# 本地模型接入

影策负责用户、项目、模型目录、价格、任务队列、执行回执、资源和费用记录。`model-gateway/` 只转换本地推理请求与 ComfyUI 回执，不保存项目、不建立另一套任务中心。原 New API 和旧网关可以继续独立保留。

## 启动传输服务

使用已安装的 Ollama、ComfyUI 和模型权重。在仓库根目录安装 `model-gateway/requirements.txt`，然后运行 `python model-gateway/gateway.py`。默认监听 `127.0.0.1:8001`，单进程运行。可配置 `COMFY_URL`、`OLLAMA_URL`、`TEXT_MODEL`、`MODEL_GATEWAY_PORT` 和持久化的 `MODEL_RECEIPT_DIR`。默认文本模型为 `qwen3.5:9b`。

`workflows/` 固定了本次实际使用的 FLUX.2 Klein 4B 与 Wan 2.2 TI2V 5B 工作流，不包含权重。权重文件名必须与安装的 ComfyUI 一致。服务切换前会等待现有 ComfyUI 队列空闲，再释放本传输使用的模型；不会中断其他客户端的任务。

传输无鉴权，保持本机监听，不直接对公网开放。影策通过精确的 `CANVAS_ALLOWED_PRIVATE_UPSTREAM_HOSTS` 放行管理员配置的服务地址；不使用允许全部私网的开关。

## 配置影策

离线配音可独立运行 `model-gateway/audio_gateway.py`，使用 `yingce-local-audio` 系统协议及 `chatterbox-multilingual` 模型名。单独创建无密钥的管理员渠道，地址指向配音传输；不能将其他已在运行的文本、图片或视频渠道改成配音渠道。运行时只读取已安装的 Chatterbox Multilingual 权重和音频 Python 环境，配置方式见仓库中的 `model-gateway/README.md`。本地生产启动器也支持与环境文件同目录的 `.local-speech-models.json`，配置 `speechOnly: true`、独立端口、回执目录及 `speechPython`、`speechModelDirectory`、`speechFFmpeg`。

画布的添加菜单直接选择“配音”，新手和专业模式都能进入。节点显示当前模型，“音频设置”集中选择语言、0.5–2倍语速及 WAV/MP3/FLAC/Opus；原“音频”节点仍用于上传和播放素材。配音输入框只填写需要朗读的原文，每段不超过3000字。默认声音与参考音色明确区分。参考音色需连接3–20秒的清晰讲话音频，或绑定了该声音的角色卡，并确认这份声音的使用授权。更换参考后重新确认；后端从有权限的原始素材读取音频并探测实际时长，不相信浏览器自带的替代字节或网址。角色简介、Skill 指令和素材标签不会附加到本地配音台词；自由文字声音指令不受该模型支持，清空指令后不会重新继承旧的全局指令。

配音复用原生任务、预算、结果入库、定向取消及丢失回执恢复。服务重启后不会自动重跑未完成推理，先查询原任务及其产物。参考临时文件在完成和取消后清理，原文件、输出与回执保留。音色与发音仍需结合实际片段试听和台词核对；生成成功本身不代表配音质量通过。

1. 管理员创建系统渠道，填写本地服务地址，密钥留空。共享同一显卡的三个模型放在同一渠道，渠道并发设为 1。
2. 添加渠道模型，分别选择“本地文本 · Ollama”“本地图片 · ComfyUI”“本地视频 · ComfyUI”协议。实际模型标识分别为 `qwen3.5:9b`、`flux2-klein`、`wan2.2-ti2v-5b`。不匹配的标识会被拒绝，不会静默运行另一模型。
3. 显式配置实际能力和价格。本地免费可设置按次价格 0，同时标记价格已配置。图片支持单张输出及 `1:1`、`16:9`、`9:16`；视频支持横竖画幅、1–10 秒，默认 720p（1280×704 或 704×1280），288p 仅供快速预览。文本关闭流式，上下文 8192、最大输出 2048。
4. 在前台模型目录关联对应渠道模型并启用“前台模型”。普通用户选择模型即可生成，无需创建个人 API Key。

三个本地协议各接受一张 PNG/JPEG/WebP 参考图：Qwen 看图、FLUX 图片修改和 Wan 视频首帧。单图上限 8 MiB、1600 万像素，模型输入等比例缩小至最长边 1024，原素材保留。系统先校验影策素材归属并读取实际像素；网关不抓取用户提供的外部地址。遮罩、尾帧、参考音视频和视频原生音频尚未接通，不能声明为支持。

文本请求以 UTF-8 字节、对话开销、视觉预留及输出上限进行保守上下文检查；超过预算明确拒绝，避免 Ollama 静默截断。此检查不是精确分词计数，较长文本可能需要缩短或分段。

## 本地音乐

`yingce-local-music` 将已安装的 ACE-Step 1.5 Turbo 接入原生音频任务，管理员系统渠道使用 `acestep-1.5-turbo`，地址与本地图片传输相同，无需用户 API Key。音乐仍由影策负责权限、预算、队列、取消、固定素材版本与恢复；ComfyUI 仅运行计算图。

支持10–30秒的纯音乐与填词歌曲，40–240 BPM，以及普通话、粤语、英语、日语、韩语歌词。提示词描述音乐风格，`audioLyrics` 只填写实际演唱内容。纯音乐须清空歌词；模型不支持参考音色、参考图片或参考视频，不承诺精确演唱、逐字时间戳或实际节拍。生成后可分析音频并人工校对，再加入剪辑。

使用画布音频节点的“音乐制作参数”，或 Agent `generate_media` 的 `audioMusicMode`、`audioLyrics`、`audioSeconds`、`audioBpm`。后两项使用整数字符串。模型目录返回真实能力，`GET /api/models` 检查所需权重与节点，未安装时不声明可用。输出为实际保存的无损 FLAC；任务重试复用原始提交回执，不重复推理。

## 本地 CPU 分析的启动与恢复

节拍、参考视频分段和主体跟踪使用独立的无状态 CPU 服务，任务、源素材、校正版本及采用记录仍保存在影策。为已有 Python、FFmpeg 和私网连接准备 `.local-analysis.json`，放在本地生产 `.env` 同目录。配置字段为 `version: 1`、`python`、`relayPython`、`ffmpeg`、`directory`、`tokenFile`、`workerPort`、`windowsRelayPort`、`dockerRelayPort`；路径必须是本机绝对路径，目录沿用仓库工作进程的归属记录。启动器不会自动下载运行时。

`scripts/start-production-local.ps1` 自动发现该配置并恢复缺失的已归属分析进程与私网转发；`-ProbeOnly` 同时检查分析服务。配置了分析但服务缺失时，即使后端存活也返回失败。可用 `scripts/start-media-analysis-local.ps1 -ConfigFile <配置文件> -ProbeOnly` 单独检查；检查不会启动或替换服务，监听范围保持本机与 WSL 私网。

本地生产备份包含该启动配置与签名密钥，核对密钥和原生数据中配置的签名文件一致。密钥必须位于后端 `/data` 内并进入原生备份。分析模型权重、测量缓存和进程 PID 不进入启动配置归档；已保存分析及校正由原生数据库和素材备份恢复。旧备份没有此可选归档时继续按原有范围恢复。

使用 `python scripts/production_analysis_backup.py --backup <备份目录> --output <新的私有目录> --repository <当前仓库>` 准备独立分析服务，默认使用13006、18006、18007三个新端口，再用生成的 `config.json` 启动。此步骤校验归档、签名和文件摘要，重新建立归属记录，保留原服务；不会安装权重或运行生成模型。

## 本地 Agent 工具调用

本地文本协议也可作为影策原生 Agent 的模型。独立 `yingce-agent` 仍通过 Go 模型桥提交文本任务；网关的 `POST /api/agent/generate` 仅转换会话、工具声明及模型响应，不执行工具。工具结果按原调用 ID 对应；实际写入、模型目录、素材归属、审批和预算继续由影策处理。只读模式可查询媒体模型，不能创建节点或提交生成。

完整工具上下文建议为本机已验证的 Qwen 配置 32768 上下文、2048 输出、关闭文本流式。系统渠道执行时重新加载管理员能力合同，不能信任客户端提交的限制。工具调用暂只支持自动选择；不支持强制指定工具的请求会明确失败。

长中文 Agent 上下文可设置 `AGENT_TOKENIZER_DIR`，目录含 `tokenizer.json` 和 `verification.json`。分词文件必须固定来源版本与 SHA256，并逐项匹配安装模型的词表、合并规则和模型 digest。运行时离线读取文件，每次新推理通过 Ollama 目录校验 digest；模型被替换后需重新验证。计算完整会话及工具声明的分词数，另预留至少4096模板空间、图片空间及输出额度。这是有模板余量的准入估算，实际用量只取 Ollama 返回值；不删减历史、不把估算当实际消费。未配置分词器时仍可使用保守字节预算；配置文件损坏只阻止 Agent，不关闭媒体回执和取消接口。

准备已有分词文件后，使用仓库内的核对工具写入验证记录，不需要下载模型权重。例如本机已经核验的固定版本：

```sh
python model-gateway/verify_tokenizer.py --directory /path/to/qwen-tokenizer --model qwen3.5:9b --source https://huggingface.co/Qwen/Qwen3.5-9B --revision c202236235762e1c871ad0ccb60c8ee5ba337b9a --sha256 5f9e4d4901a92b997e463c1f46055088b6cca5ca61a6522d1b9f64c4bb81cb42
```

该工具检查已有 `tokenizer.json` 的 SHA256、全部基础词项、附加词项、合并规则与当前 Ollama 模型 digest，再原子保存 `verification.json`。新模型或新版本需要其自己的固定来源及匹配结果，不能直接沿用示例记录。普通文本与 Agent 使用同一管理员上下文和输出合同，启用已验证分词器后也可接收长中文文本。健康检查中的 `agent_tokenizer_ready` 还会核对当前模型 digest；服务进程存在不能证明分词器已经加载。已有服务未配置分词器时，可为本地 Agent 单独配置 `.local-agent-models.json`，设置 `agentOnly: true`、`agentTokenizerDirectory`、独立端口及回执目录；启动器使用独立的进程记录并要求分词器就绪。管理员将 Agent 文本模型指向该入口，旧任务继续使用原来的服务配置。

提交标识来自原生持久化执行尝试，仅放在请求头。模型响应及稳定工具 ID 保存在传输回执中；丢失响应或最终转换写入失败时，Go 读取原回执恢复，不重复推理。无法核验的结果保留失败和诊断，停止自动创建另一个本地模型步骤。恢复实例必须把 `YINGCE_AGENT_BRIDGE_HOST` 指向自己的后端容器名，避免临时模型桥误连主环境；远程 Agent 失败时不回退到嵌入执行。

新增节点提案须同时包含节点类型、标题和所需正文。请求审批模式先提交提案，由平台在实际写入前生成审批卡；聊天中的“请审批”不能代替审批。工具参数失败后若模型自行结束，服务端会以真实未成功回执进行一次有上限的继续核对；剩余错误未解决时显示失败，不把模型口头成功当成写入完成。该核对不重放结果不明的推理，也不重新提交收费媒体任务。

Wan 工作流实际使用 24fps，帧数为 `秒数×24+1`，实际文件时长可能多一帧。视频保存时通过 FFprobe 读取真实几何和时长；时间线使用实际媒体时长。已有未知时长的资源在加入剪辑前由浏览器探测，失败时保留素材并提示用户。

## 回执和异常

影策在首次派发前将模型服务、能力参数和代理配置加密绑定到本次执行尝试。管理员后来编辑、停用或删除渠道时，旧任务的轮询、取消及下载仍读取原配置。进程重启后本地任务若缺少提交响应，只查询原尝试的回执；缺失或损坏回执不会触发第二次推理。旧系统渠道任务没有该配置时需要人工核对，不能拿当前配置冒充原服务。数据库需先升级到 Schema62，备份同时保留 `.settings-key`。

- `POST /api/submit` 提交图片或视频，立即返回 ComfyUI `prompt_id`；`GET /api/jobs/:id` 查询原队列或历史。
- `POST /api/generate` 调用本地文本或视觉模型；`GET /api/health` 检查服务入口；`GET /api/models` 核对 Ollama 标签及 ComfyUI 实际加载器中的 UNet/CLIP/VAE 文件名，返回缺失权重和可用性。
- 图片和视频产物通过 `GET /api/jobs/:id/outputs/:index` 流式读取，避免容器后端被宿主机 loopback 地址阻断。返回相对地址，由影策按已配置的网关地址解析；原始 ComfyUI 地址不发给浏览器。
- 提交必须携带 `Idempotency-Key`。持久化回执按键哈希存放。同一键、不同输入返回 409；损坏回执拒绝重发。
- 创建响应丢失时，影策只读 `GET /api/receipts/:digest` 核对。传输可从原 ComfyUI 队列和最近历史恢复回执，找不到时保留不确定状态，不自动重新推理。文本结果不确定时同样停止重发。
- `POST /api/jobs/:id/cancel` 只接受有可核验影策提交回执的图片/视频任务。排队项按具体编号删除；运行项通过带 `prompt_id` 的定向中断请求停止，保留其他任务、原文件和历史。启用运行中断前须核对所装 ComfyUI 的 `/interrupt` 实现确实检查 `prompt_id`，再设置 `MODEL_GATEWAY_TARGETED_CANCEL=1`；默认不启用，不发送空请求或全局中断。
- 网关按具体任务保存索引和取消意图，重复取消及丢失响应可继续核对，不重发推理。`GET /api/health` 的 `targeted_cancel` 表示该配置开关，真实运行中断仍须单独验收。界面取消后保持“确认中”，核对到中断或排队删除回执后才确认；缺失历史不作为取消或退款证据。

## 已有本地验证及限制

已通过传输幂等与异常专项、原生任务中的真实文本/图片/视频生成、画布文本生成按钮及重新打开、生成视频加入时间线、独立浏览器恢复和实际 MP4 下载。真实视频预览为 512×288、24fps、约 1.04 秒；与三个图片片段合成为 1920×1080、约 10.04 秒的 H.264/AAC 文件。

参考图实测包含 Qwen 识别橘猫和庭院、FLUX 保持同一画面并加入蓝色围巾，以及 Wan 首帧视频。288p 样片出现色块，记录为画质失败；按[ComfyUI 官方模板](https://docs.comfy.org/tutorials/video/wan/wan2_2)使用 1280×704 后，短样片抽帧未再出现该色块。短片通过不能替代长镜头与角色连续性验收。

## 自动字幕与剪辑合成

### 本地人物口型

声音工具传输可配置可选的 `lipSyncModelDirectory`，指向已安装的 MuseTalk 1.5 工程；沿用 `mediaPython` 和 `mediaFFmpeg`。启动时验证指定权重文件摘要及依赖，`/api/health` 的 `lip_sync` 和 `/api/models` 返回实际可用性。不会自动安装或下载模型。口型与声音分离共享本地计算资源及磁盘预留，项目、任务、权限、预算和素材仍由影策管理。

管理员为系统渠道启用 `yingce-local-lip-sync` / `musetalk-1.5`。用户在图片或视频节点选择“制作口型片段”，选择画布对白、明确时间与可选人物框，确认对应素材的使用权。支持0.1–30秒；原画面宽高为偶数且在48–1280像素之间，视频为1–60整数帧率。照片沿用静态原画面，视频只使用所选真实帧；不会用循环或冻结尾帧填补不足的源视频。输入视频最大24 MiB，图片和对白各8 MiB。

口型任务保存原文件摘要、独立画面和对白起点、人物框与固定输出。上传时填写的时长不能替代实际FFprobe检查。生成新候选后需人工预览，原片及既有时间线不会被替换。关闭页面后由后台继续；中断或回执不确定时核对原任务，不自动重复模型推理。CPU处理耗时及嘴型质量需分别验收。

Agent 的 `generate_media` 可指定 `lipSyncSourceNodeId`，只沿用该节点已保存的 `lipSyncDraft`，引用原画面和其中的对白节点。Agent不能猜测人物区域、时间或使用权；报价审批绑定同一份口型设置和原文件摘要。MCP与Skills通过同一原生Agent及任务入口使用，不新增业务任务库。

自动字幕可使用已安装的 faster-whisper CPU 运行环境及本地转换模型。在网关进程设置 `ASR_PYTHON` 和 `ASR_MODEL_DIR`，后端 `CANVAS_WHISPER_BASE_URL` 指向网关。推理子进程使用离线模式及 `local_files_only`，不下载权重。上游合同为 `/inference` 的 multipart 单声道 16kHz PCM WAV，上限 32 MiB、1000 秒；语音为空或文件不完整均保留失败。

编辑器“自动字幕”选择具体音视频片段。识别任务保存项目、素材和片段身份；完成后先查看结果，再点击“采用识别字幕”。采用时按该片段当前的源裁剪和节目位置映射；同一文件的重复实例不会互相替换字幕。已有结果从原任务详情恢复，关闭重开不重新推理。本地 CPU 转写可取消，临时音频和子进程随结束或断开清理。

离线 Faster Whisper 请求真实逐词时间，保留模型返回的置信度（包括0）。不补造零时长词的时间；缺少可靠时间的词会使结果标记为不完整，按句结果仍保留。旧服务只返回句子时仍按句使用。后端拒绝超出已知来源时长的结果，不根据模型文本猜测说话人。文字稿可预听源素材及具体句词；打开文字稿和播放原音会暂停后台时间线，进入剪切预览或关闭面板时暂停原音。

成片导出支持独立音轨的裁剪、延迟、音量、淡入淡出与混音，按轨道顺序处理叠放画面，将普通字幕和文字烧入 MP4，并保留 SRT。中文字幕自动换行，最多三行；同时最多四条字幕分行显示。导出前检查项目归属、固定素材、时间和临时空间；缺失素材、异常文件、字幕溢出及不一致的实际成片时长均停止交付。单次最多 128 段；浏览器离线导出仅用于基础剪辑，复杂声音和字幕使用服务端导出。

后端镜像安装 FFmpeg 与 Noto CJK。宿主机可通过 `CANVAS_SUBTITLE_FONT` 配置字体，缺失支持中文的字体时明确失败。实际浏览器已验证独立音轨播放、人工/识别字幕采用、1080p 导出和新浏览器恢复；未将音轨存在等同于完整配音、克隆和口型功能通过。

剪辑页面还会查找当前账号、当前项目在本机保留的恢复草稿。恢复前展示片段数和时长，用户确认后以服务端当前版本保存，并先保留替换前副本。网络错误、版本冲突或本地备份失败不会变成假成功；草稿支持下载和单独删除。
