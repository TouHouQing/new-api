# 原生视频返工后续编辑闭环

主目标仍是完整合并，不在第 68 轮里程碑停止。冻结需求规格及历史 18 领域、40 条原始验收状态保持。

第 68 轮已实测：指定实例与源时间、奇数像素选区、已有真实模型候选、本地合成固定版本、构图继承、原淡入淡出、三种声音策略、网页比较与采用／撤销、实际 stdio MCP、重复素材与变速完整成片、独立恢复。其记录明确保留 MuseTalk 嘴部柔化的质量限制，不代表整套合并完成。

继续处理已发现的组合缺口：

1. 当前 V1 以独立前景修复轨覆盖选中时间。原片随后移动、拆分或变速时，覆盖片段没有相同的编辑关系；较低轨道的原片被其他视频遮挡时，新增前景可能改变无关画面。不能只以其他片段 JSON 未变认定画面保留。
2. 修复请求意图保存在当前浏览器。原任务、文件和回执虽然在服务端，任务中心返回剪辑时仍只带片段 ID，新浏览器不会自动读取其完成候选。需要带任务 ID 进入并从原生任务恢复；不能创建新编号来假装恢复。
3. 指针在最后一个像素落下且没有拖动时，左上角被调整而宽高使用未调整坐标，可能得到 1px 选区。统一边界计算并做实际指针测试。

优先评估 V2：将所选时间／区域合成进保留原文件完整源时间的独立候选，采用时更新同一具体片段的固定资源／版本，保留片段 ID、时长、源裁剪、速度、混音和跟随关系，使用常规轨道优先级。取消额外前景轨，其他素材使用和源文件保留。随后移动、拆分和变速沿用正常片段功能。候选比较应跳到正确的输出源时间，不能假定输出从所选范围的第零秒开始。

采用和撤销继续使用原生编辑预览、CAS、前后版本和回执。撤销要能在保留后来位置／裁剪／速度／音量等改动的同时恢复原资源；已校正构图必须有正确原资源 SHA、源时间和原生历史，不能指向错误媒体或把手工继承写成新算法测量。已有 V1 任务、候选、回执和固定成片保持可读与原有重放语义，不重新推理、不静默迁移历史正文。

整源处理须明确实际时长、输入／输出字节、临时文件、CPU 租约和超时限制；超过容量时安全停止、保留原文件并提供先裁剪另存的路径，不能截断后当成功。需要保留分段边界、跟随音频、字幕、标记、重构图与候选来源的原生校验。

后续验收至少包括修复前后变速、修复后移动／裁剪／拆分、上下视频轨遮挡、同素材独立使用、独立与跟随声音字幕、构图与标记、三种声音、原浏览器和新浏览器找回、未知回复重放、局部撤销、完整导出和独立恢复。禁止以静态入口、测试替身或字段存在代替真实使用。

完成上述后继续歌词实测对齐、专用分层模型的持久任务合同、角色／商品连续性质量、网页 Agent 与 MCP／Skill 等价、剧集／交付组合及新手全流程，并对照原始 40 条建立当前验收映射。外部发布未授权，禁止为了验收向外部平台发送作品。
